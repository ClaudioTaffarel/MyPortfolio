# Claudio's portfolio · Revision 2

Ekstrak ZIP dan buka `index.html`, atau gunakan Live Server di VS Code. Tidak memerlukan npm atau proses build. Font Google membutuhkan internet; gambar, ikon, dan CV tersedia lokal.

**Panduan lengkap:** buka `PANDUAN.md` untuk penamaan file, mengganti foto hero, menambah screenshot, memasukkan sertifikat, dan menambah proyek baru beserta contoh objek lengkap.

Perubahan Revisi 2:

- Wave menjadi lapisan di atas satu sticky sky, bukan blok oranye terpisah. Wave bergeser saat scroll di depan latar langit.
- Tulisan “LET CURIOSITY TAKE FLIGHT” dihapus.
- Doodle hero diperbesar dan dipindahkan ke kiri atas, sedikit keluar frame.
- Teks lokasi dan kampus di hero dihapus.
- Jurusan memakai typewriter dengan ruang tiap karakter tetap, sehingga paragraf tidak naik-turun.
- Jumlah polaroid, tombol navigasi, dan panjang perjalanan scroll mengikuti jumlah proyek.

Pengaturan reduced motion dari OS tetap didukung. Screenshot proyek dan sertifikat menggunakan aset asli yang tersedia, dengan placeholder kosong untuk sertifikat yang belum diisi.

Validasi: Chromium pada viewport 320, 390, 768, dan 1440 px, kedua transisi diperiksa secara visual, typewriter tidak mengubah tinggi paragraf, reduced motion berfungsi. Penambahan proyek kelima diuji dengan data sementara dan berhasil menambah polaroid, navigasi, panjang scroll, dan popup. Tidak ditemukan error JavaScript. Ini tes browser dengan emulasi viewport, bukan perangkat HP fisik.
